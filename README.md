# Customer 360 Intelligence

An end-to-end **Data Science and Machine Learning project** that analyzes customer behavior, builds predictive models, and segments customers to support data-driven business decisions.

The project follows a complete machine learning workflow, from data collection and cleaning to **EDA, feature engineering, supervised learning, and unsupervised learning**.

---

## 📌 Project Overview

Businesses often have customer data spread across multiple dimensions such as demographics, usage behavior, satisfaction, support interactions, revenue, and subscription information.

The goal of this project is to build a **Customer 360 Intelligence system** that provides a comprehensive view of customers and answers questions such as:

* Which customers are generating high revenue?
* What factors are related to customer satisfaction?
* Which customers are likely to have high future revenue?
* Can customers be grouped into meaningful behavioral segments?
* What customer characteristics can help businesses make better decisions?

---

## 🎯 Business Objectives

The project focuses on three main objectives:

### 1. Customer Understanding

Analyze customer demographics, usage patterns, satisfaction, tenure, support interactions, and financial behavior.

### 2. Revenue Prediction

Build regression models to predict **Future 12-Month Revenue (EGP)** and identify the factors associated with future customer value.

### 3. Customer Segmentation

Apply clustering techniques to discover customer segments based on their behavior and characteristics.

---

## 📊 Dataset

The project uses a customer-level dataset containing information about:

* Customer demographics
* Subscription information
* Tenure
* Internet and service usage
* Monthly usage
* Satisfaction scores
* Support interactions
* Revenue and charges
* Customer behavioral characteristics

### Target Variable

For the regression task:

**`Future12MRevenueEGP`**

This variable represents the expected revenue generated by a customer over the next 12 months.

The data cleaning stage prepares the dataset for analysis and modeling.

# 🛠️ Feature Engineering

Feature engineering is used to create additional features that provide more meaningful business information.

Examples include:

### Support-Satisfaction Interaction

`SupportSatisfactionInteraction`

Combines support interaction behavior with customer satisfaction to capture the relationship between customer support and satisfaction.

### High-Value Customer

`HighValueCustomer`

Identifies customers based on their financial value.

### Estimated Total Charge

`EstimatedTotalCharge`

Provides an estimated customer charge based on available customer information.

### Tenure Groups

Customers are grouped according to their tenure to analyze differences between newer and longer-term customers.

### Other Engineered Features

Additional features are created from customer usage, financial, satisfaction, and behavioral variables.

> Features that directly represent future revenue or contain information unavailable at prediction time are excluded from the regression model to reduce the risk of **data leakage**.

# 🤖 Supervised Learning

## Regression

The main supervised learning task is predicting:

**`Future12MRevenueEGP`**

Several regression algorithms are evaluated, including:

* Linear Regression
* Ridge Regression
* Decision Tree Regressor
* Random Forest Regressor
* Gradient Boosting Regressor

### Evaluation Metrics

The regression models are evaluated using:

* **MAE** — Mean Absolute Error
* **RMSE** — Root Mean Squared Error
* **R²** — Coefficient of Determination

Example evaluation format:

| Model             | MAE | RMSE | R² |
| ----------------- | --: | ---: | -: |
| Gradient Boosting |  370.529531	| 468.032432 | 0.895445 |
| Lasso Regression  |  379.542112 |	476.230788 | 0.891750 |
| Ridge Regression  |  380.236481 | 477.135861 | 0.891338 |
| Linear Regression |  380.274272 | 477.181907 | 0.891317 |
| Random Forest     |  392.970177 |	498.656565 | 0.881315 |
| Decision Tree     |  512.525450 |	648.685333 | 0.799154 |
| KNN Regressor     |  641.676657 |	810.185708 | 0.686698 |

The final model is selected based on the evaluation results and the project objective.
The final model is Gradient **Boosting Regressor**

# 🔵 Unsupervised Learning

Customer segmentation is performed to discover groups of customers with similar characteristics.

## K-Means Clustering

K-Means is used to divide customers into different clusters based on selected behavioral and customer-value features.

The number of clusters is investigated using techniques such as:

* Elbow Method
* Silhouette Score

The resulting clusters are then analyzed to understand the characteristics of each customer segment.

---

## DBSCAN

DBSCAN is also explored as a density-based clustering algorithm.

It can identify:

* Dense customer groups
* Irregularly shaped clusters
* Potential outliers/noise

Important parameters include:

* `eps`
* `min_samples`

The clustering results are compared with K-Means to better understand the customer population.
